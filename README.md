# Time Series Forecasting

A practical collection of time-series analysis and forecasting techniques designed by Kaggle, which are for understanding temporal data and building predictive models.

This repository combines theoretical concepts with hands-on implementations using real-world datasets.

You can find the official Kaggle course here: [Time Series](https://www.kaggle.com/learn/time-series)

---

## Topics Covered

- Introduction to Time-Series Data
- Time-Series Exploratory Data Analysis
- Data Visualization
- Trend Analysis
- Seasonality & Cyclic Patterns
- Stationarity
- Time-Series Data Preprocessing
- Resampling & Rolling Windows
- Time-Series Forecasting
- Machine Learning for Time-Series
- Forecast Evaluation
- Anomaly Detection
